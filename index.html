FAQ

Common questions.

Answers to what people ask before their first build.

Do I need to know Python or how to code? ▼
No. You never write or edit code. Claude generates all scripts automatically based on your plain-English description. The only commands you run are python3 next_setup.py (once) and python3 next_teardown.py (to clean up) — both are copy-paste.
What if I don't have a Tableau Next org? ▼
You'll need a Salesforce org with Data 360 and Tableau Next provisioned. If you don't have one, contact your Salesforce account team or internal demo environment team. This tool can't provision an org — it builds inside one you already have access to.
How do I know what metrics to ask for? ▼
You don't need to know upfront. Just describe the business story — "customer churn is rising" or "sales pipeline has stalled" — and Claude will suggest appropriate metrics and classify them correctly. You review and approve before anything gets built.
What if the build fails partway through? ▼
Paste the error message into Claude and ask what happened. Claude can diagnose and fix most API errors on the fly, then continue the build from where it left off. The docs/troubleshooting.md reference file contains fixes for the most common issues.
Can I customize the demo after it's built? ▼
Yes. Tell Claude what you want to change — "update the color scheme", "add a Net Promoter Score metric", "change the dashboard layout" — and it will make the targeted updates. You can also edit assets directly in the Tableau Next UI after the build.
Can I build demos for any industry? ▼
Yes — retail, healthcare, financial services, manufacturing, media, technology, and more. Claude generates industry-appropriate data, signals, and metric names automatically based on the scenario you describe. No industry-specific configuration needed.
