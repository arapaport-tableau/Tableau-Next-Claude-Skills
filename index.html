How it works

From description to demo in three steps.

No JSON. No API calls. No setup beyond one-time org credentials.

1

Connect your org

Run the setup script once per Salesforce org. Claude walks you through creating a Connected App and stores credentials securely in next_orgs.json.

python3 next_setup.py
2

Describe the demo

Tell Claude the company, the persona, the story, and the metrics you want to highlight. Claude proposes a plan and waits for your approval before building anything.

/build-next-demo
3

Say go — then present

Claude builds everything automatically in 8–15 minutes. You get a Mac notification when it's done. Open Tableau Next and your demo is ready.

type "go" → done

Getting started

Up and running in 30 minutes.

Everything you need is in this repo.

📋 Prerequisites

  • Claude Code installed — claude.ai/code
  • Python 3.10+
  • Salesforce org with Data Cloud and Tableau Next provisioned
  • Admin access to create a Connected App
  • See SETUP.md for the full manual setup walkthrough

🚀 Build your first demo

  1. Open this folder in Claude Code
  2. Run python3 next_setup.py to connect your org
  3. Type /build-next-demo and describe the demo
  4. Review the plan Claude proposes, then type go
  5. Get a Mac notification when the build completes
  6. Run python3 next_teardown.py to clean up after the demo
